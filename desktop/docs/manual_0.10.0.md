# DrawIQ 0.10.0 — 地端工程圖覆核工作台

基於 DrawIQ_Workbench 的 0.9.1 完整工程開發，沒有使用桌面 0.3 簡化介面取代工作流程。

## 啟動與資料

在本機雙擊 `啟動_DrawIQ_0.10.0.bat`。這個入口使用原本 `DrawIQ_Workbench\data` 的帳號與工作資料；登入方式相同。不要同時用兩個版本編輯同一份文件。原 0.9.1 程式目錄保留。

直接執行新版資料夾的 `run.bat` 則使用新版自己的 `data`，首次使用需建立管理者。命令列 `run.bat --data "指定資料夾"` 可選獨立工作區。

本次測試只在 `qa\real_*\data` 及暫存測試資料庫執行，沒有在正式資料庫中測試核准、發布、刪除或訓練。沒有複製或重設正式帳號，也沒有預設共用密碼。

## 操作

1. 登入後選「匯入並讀圖」或「載入既有成果」。
2. 中央下方選 OCR 模型，預設 RapidOCR 四向比對。橫置頁面會先比較四個方向，再以同一方向進行 OCR、欄位解析和原圖座標轉換。方向不確定時維持原方向。
3. 左側候選、中央原圖、右側報價資訊一起核對。選「詳細條件」可確認尺寸上下公差、單位、對象及範圍。
4. 缺字可放大、框選重讀、手動補入符號；選框維持固定 RapidOCR，以使用者選定的角度重讀。整頁可切換 Indra 作替代候選。需要明確角度時在辨識設定選旋轉 90／180／270 度。
5. 逐項確認證據與用途，再依原流程核准、發布和匯出。內容改動會使相關確認失效，既有發布快照仍保留。候選、模型分數、SHACL 通過都不等於人工確認。

原有帳號管理、強制初次改密碼、停用與登出、版本衝突檢查、人工排除、報價帶入、學習回饋和稽核紀錄沿用。角色仍為管理者與一般使用者，沒有宣稱已完成 SSO 或多人分級簽核。

## 新功能與限制

- RapidOCR 固定 3.10.0；沿用已驗證 SHA-256 的 PP-OCRv6-small ONNX 權重。四向模式為方向比對，分區精讀是另外的選項，識圖時不下載權重。
- Indra 固定 1.1.2，權重固定官方 v1.1.0 對應 commit；實際下載檔與 SHA-256 在 `models/indra-v1.1.0/manifest.json`。模型盒座標映回原始頁面，Indra 不保證工程小字／手寫或方向均正確。
- 新的型別解析保留 `±`、`+/-`、`+0/-0.36`、比較符號、螺紋等級，以及明確三段標註的直徑／螺距／長度。`M3x6` 兩個數字不擅自指定螺距或長度；`200M` 保留原文並標待決定，不自動乘千。解析器不會將 OCR 的 `110` 偷改為 `10`。
- 每個新解析候選都連結來源框、原文、方法版本，初始為未確認。重跑不覆蓋既有人工值。
- 證據包新增 `evidence.jsonld` 和 `graph_validation.json`。`trustedFactIds` 只收有證據且人工確認的有值需求；候選與衝突不進入可信清單。SHACL 只驗資料結構，工程正確性仍由覆核決定。
- VLM 預設關閉，避免未安裝 Ollama 時誤以為已執行。原本最多四個本機模型的功能保留，可自行啟用。沒有重訓 OCR 權重。
- 未取得使用者提到的 `DrawIQ_OCR_Knowledge_Upgrade_20261022.zip`；本版自行實作並測試上述串接，沒有宣稱已匯入該包的 34 個測試。eDOCr2、OBB、MechVQA、DTRT 不在本版執行路徑。

## 驗證與重現

`python tools/run_harness.py --suite full` 執行隔離的完整回歸，結果含程式指紋、16 個契約案例與測試日誌。這不是 OCR 準確率。

`python qa/run_actual.py rapid_auto indra_auto` 以現有 A–F 原始 PDF 的獨立副本跑實際模型；各 run 保存來源 SHA、原文、框、候選、公差、時間和完成狀態。最後的實圖驗收報告另列成功與未解項，無法判讀或源頭矛盾的資料不當作正解。

本機 `.venv` 已安裝。換機需 Python 3.13 x64，執行 `install_0.10.0.bat` 依 `requirements-lock-0.10.0.txt` 安裝套件；權重隨更新包提供。模型修復工具會明確連線官方模型庫，不會在每次辨識偷偷下載。

- [RapidOCR 3.10.0 官方版本](https://github.com/RapidAI/RapidOCR/releases/tag/v3.10.0)：新版引擎；程式與權重來源須分別保留授權。

- [RDFLib](https://github.com/RDFLib/rdflib)、[pySHACL](https://github.com/RDFLib/pySHACL)：本機來源圖譜與結構驗證；保留套件授權。
