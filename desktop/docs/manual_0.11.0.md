# DrawIQ 0.11.0 台灣耐落報價工作台

## 登入

首次使用請輸入通用帳號 `user` 與密碼 `user`。接著設定自己的四位數帳號和四位數密碼，完成後進入工作台。帳號與密碼可以是相同的四位數，可用前導零。已建立的個人帳號與原有帳號都可直接登入。通用登入用於建立新的個人帳號。帳號已存在時，請使用其他四位數或登入原帳號。

## 匯入與核對

從上方選「匯入並讀圖」開啟 PDF 或圖片，系統用 RapidOCR 和 MinerU Basic 辨識，直接預填左側報價欄位。也可載入既有成果。上方檔名選單可切換圖面，中央選單可切換頁次。

| 區域 | 操作 |
| --- | --- |
| 左側耐落報價欄位 | 依報價標籤順序顯示 18 個欄位及根據原圖來源預填的建議值。點欄位可切換備選、改內容或單位。無可用讀值會顯示「待補」，人工核對後也可標為「圖面未提供」或「不適用」。 |
| 中央工程圖 | 用「彩色標註」在圖面標註與原圖間切換。紫色是規格，綠色是材質，橘色是塗膠，藍色是品質及注意事項，青色是報價與聯絡資料，灰色是其餘來源。 |
| 右側各方法結果 | 可篩選已執行的方法與頁次。點右側有來源的結果會置中放大原圖，點原圖色框會跳到對應結果。虛線用於圖形版面定位。可在「全文」及「JSON」查看目前篩選，並從「匯出目前結果」另存 Markdown 或 DrawIQ JSON。 |

報價欄位依序是報價單號、專案代號、報價人員、報價日期、報價有效日期、客戶、材質、報價膠別、顏色、塗佈方式、規格、數量、報價、品質要求、包裝方式、注意事項、聯絡電話、客戶傳真。報價欄只印幣別和計價單位時，會顯示待補金額。數量與單位分別保留，原圖的 `M` 保持原樣。

選左側要改的欄位，按中央「框選並辨識」，在原圖拖出範圍。兩套工具會辨識框內文字，將可用的內容和單位回填到該欄。兩種讀值不一致時，可從「其他辨識結果」換值，也可直接修改。框內無可用文字時，可在左欄手填，系統保留所選原圖框。

核對畫面後，按「核准報價標籤」或 Ctrl+Enter，會開啟最後輸入視窗。左側可從原圖帶入的內容繼續編修，或填入價格、專案代號等承辦資料。右側可預覽最後的列印版面。按「回到圖面」可繼續核對，按「核准並輸出圖片」完成當次核准。

核准會同時保留原圖核對、承辦輸入和正式標籤快照。承辦輸入會各自記錄來源，沒有可用資料的欄位保留待補。重讀圖面或修改來源後，可核對新結果再核准。

## 輸出報價標籤圖片

核准會儲存黑白 PNG 到工作區的 `exports`，並開啟預覽。圖片依標籤原順序列印 18 欄，紙上寬度預設 100 mm、300 dpi，長文字自動換行。未填欄位以空線顯示。已有計價單位時保留單位和空白金額線。

按「複製圖片」可貼入報價單，也可用「另存 PNG」在報價單內插入圖檔。日後選「查看／輸出標籤圖片」可重新產生同一份核准資料的圖片。要改正式值時選「修改最終資料」重新確認。

## MinerU 辨識

在上方辨識方法選擇「MinerU Flash · 本機」、「MinerU Basic · 本機」或「RapidOCR ＋ MinerU Basic」，再按「重新辨識」。預設整頁比對與框選辨識會依序執行兩個方法。重新辨識可選「本頁」或「全部頁」；勾「強制 OCR」時，當次從圖像讀字，忽略 PDF 的內嵌文字層。安裝本機 VLM 權重後，辨識選單也會出現 MinerU Advanced。實測範圍及另一台電腦的配置請見 [MinerU 本機辨識與評估](mineru_0.11.0.md)。

## 報價草稿

上方「報價草稿」列出確認數及必要缺項，可直接匯出規格草稿。承辦人填齊本次批量、幣別、費用及毛利等資料後，可試算未稅金額。圖面或核對內容更新時，先重新開啟草稿並核對成本。正式工程核准與發布在「進階工具」。

## 啟動與驗證

安裝 Python 3.13 x64，從桌面版資料夾依序執行 `install_0.11.0.bat` 與 `run.bat`。第三方模型來源及限制見 [0.10.0 手冊](manual_0.10.0.md)。

在版本資料夾執行 `.venv\Scripts\python.exe tools\run_harness.py --suite full` 可重跑隔離驗證。
